# LeadScout

AI-powered business lead finder.

Finds local businesses without websites using:
- Google Maps
- 2GIS

## Features

- Search businesses by city and category
- Extract phone numbers
- Detect missing websites
- Export leads to Excel

## Tech Stack

- Python
- Playwright
- Pandas
- OpenPyXL

## Run

```bash
pip install -r requirements.txt
python main.py
